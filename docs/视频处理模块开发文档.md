# 视频处理模块开发文档

## 模块概述

视频处理模块是智看视频的核心功能，负责视频的上传、处理、分析和内容提取。

## 处理流程

```
视频上传/导入
    │
    ▼
音频提取 (FFmpeg)
    │
    ▼
ASR 转文字 (Whisper)
    │
    ▼
AI 内容分析
    ├─ 生成摘要
    ├─ 章节划分
    └─ 内容分类
    │
    ▼
处理完成
```

## 第一步：视频上传 + 基础信息存储

### 目标

实现视频文件上传接口，将视频保存到本地，提取基本信息并存入数据库。

### 功能需求

| 功能 | 说明 |
|------|------|
| 文件上传 | 接收 multipart/form-data 格式的视频文件 |
| 文件校验 | 校验文件格式、大小 |
| 本地存储 | 按日期分目录存储视频文件 |
| 信息提取 | 使用 FFmpeg 提取视频时长、格式等信息 |
| 数据持久化 | 保存视频记录到数据库 |

### 技术选型

| 组件 | 技术 |
|------|------|
| 视频上传 | Spring MultipartFile |
| FFmpeg 集成 | ffmpeg-cli-wrapper (Java 命令行工具库) |
| 文件存储 | 本地文件系统 |
| 数据库 | MySQL (MyBatis-Plus) |

### 数据库设计

#### Video 表

#### SQL 建表语句

```sql
CREATE TABLE `video` (
    `id` BIGINT NOT NULL COMMENT '视频ID',
    `userId` BIGINT DEFAULT NULL COMMENT '用户ID',
    `title` VARCHAR(255) NOT NULL COMMENT '视频标题',
    `url` VARCHAR(512) NOT NULL COMMENT '视频文件路径',
    `duration` BIGINT DEFAULT 0 COMMENT '视频时长（秒）',
    `fileSize` BIGINT NOT NULL COMMENT '文件大小（字节）',
    `status` VARCHAR(20) NOT NULL DEFAULT 'WAITING' COMMENT '处理状态: WAITING/PROCESSING/SUCCESS/FAILED',
    `transcript` TEXT COMMENT '转写文本',
    `summary` TEXT COMMENT '摘要内容',
    `chapters` JSON COMMENT '章节数据',
    `type` VARCHAR(20) NOT NULL COMMENT '视频类型: UPLOAD/URL',
    `format` VARCHAR(20) NOT NULL COMMENT '视频格式: mp4/avi/mkv/webm',
    `errorMessage` TEXT COMMENT '错误信息',
    `createTime` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    `updateTime` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    `isDelete` TINYINT NOT NULL DEFAULT 0 COMMENT '逻辑删除: 0未删除/1已删除',
    PRIMARY KEY (`id`),
    KEY `idx_userId` (`userId`),
    KEY `idx_createTime` (`createTime`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='视频表';
```

#### 步骤 6：创建文件存储工具类

**为什么要这样做**：
- 将文件存储相关的操作封装成工具类，实现职责分离
- 复用性高，其他需要文件操作的地方也可以使用
- 便于单元测试和维护

**达到什么目的**：
- 提供保存视频文件的方法，包含完整的校验和保存逻辑
- 校验文件：非空校验、大小校验、格式校验
- 生成唯一文件名（使用时间戳避免重复）
- 按日期分目录存储，便于管理和查找
- 解析文件大小配置（支持 GB/MB/KB 单位）
- **使用 java.nio.file.Path 实现跨平台路径处理**

文件位置：`src/main/java/com/anwen/xiamubackend/utils/FileStorageUtil.java`

```java
@Slf4j
@Component
@RequiredArgsConstructor
public class FileStorageUtil {

    private final StorageConfig storageConfig;

    /**
     * 保存视频文件
     * @param file 上传的文件
     * @return 保存后的文件路径
     */
    public String saveVideo(MultipartFile file) {
        // 校验文件
        validateFile(file);

        // 生成文件名
        String fileName = generateFileName(file.getOriginalFilename());

        // 生成存储路径（跨平台）
        Path relativePath = generateRelativePath();
        Path fullPath = Paths.get(storageConfig.getVideoPath(), relativePath.toString(), fileName);

        // 确保目录存在
        File directory = fullPath.getParent().toFile();
        if (!directory.exists()) {
            directory.mkdirs();
        }

        // 保存文件
        try {
            file.transferTo(fullPath.toFile());
            log.info("视频文件保存成功: {}", fullPath);
            return fullPath.toString();
        } catch (IOException e) {
            log.error("视频文件保存失败", e);
            throw new BusinessException(ErrorCode.SYSTEM_ERROR, "文件保存失败");
        }
    }

    /**
     * 校验文件
     */
    private void validateFile(MultipartFile file) {
        if (file == null || file.isEmpty()) {
            throw new BusinessException(ErrorCode.PARAMS_ERROR, "文件不能为空");
        }

        // 校验文件大小
        long size = file.getSize();
        long maxSize = parseSize(storageConfig.getMaxFileSize());
        if (size > maxSize) {
            throw new BusinessException(ErrorCode.PARAMS_ERROR, "文件大小超过限制");
        }

        // 校验文件格式
        String originalFilename = file.getOriginalFilename();
        if (originalFilename == null) {
            throw new BusinessException(ErrorCode.PARAMS_ERROR, "文件名不能为空");
        }

        String extension = getFileExtension(originalFilename);
        List<String> allowedFormats = storageConfig.getAllowedFormats();
        if (!allowedFormats.contains(extension.toLowerCase())) {
            throw new BusinessException(ErrorCode.PARAMS_ERROR, "文件格式不支持");
        }
    }

    /**
     * 生成文件名
     */
    private String generateFileName(String originalFilename) {
        String extension = getFileExtension(originalFilename);
        return "video_" + System.currentTimeMillis() + "." + extension;
    }

    /**
     * 生成相对路径（按日期）
     * @return 日期路径对象
     */
    private Path generateRelativePath() {
        LocalDate now = LocalDate.now();
        return Paths.get(
            String.valueOf(now.getYear()),
            String.format("%02d", now.getMonthValue()),
            String.format("%02d", now.getDayOfMonth())
        );
    }

    /**
     * 获取文件扩展名
     */
    private String getFileExtension(String filename) {
        int lastDot = filename.lastIndexOf('.');
        if (lastDot > 0) {
            return filename.substring(lastDot + 1);
        }
        return "";
    }

    /**
     * 解析文件大小
     */
    private long parseSize(String size) {
        if (size == null) {
            return 2L * 1024 * 1024 * 1024; // 默认 2GB
        }
        size = size.toUpperCase().trim();
        if (size.endsWith("GB")) {
            return Long.parseLong(size.substring(0, size.length() - 2)) * 1024 * 1024 * 1024;
        } else if (size.endsWith("MB")) {
            return Long.parseLong(size.substring(0, size.length() - 2)) * 1024 * 1024;
        } else if (size.endsWith("KB")) {
            return Long.parseLong(size.substring(0, size.length() - 2)) * 1024;
        } else {
            return Long.parseLong(size);
        }
    }
}
```

#### 步骤 7：创建 FFmpeg 工具类

**为什么要这样做**：
- 封装 FFmpeg 相关的操作，隐藏底层实现细节
- 方便后续切换 FFmpeg 库，只需修改这个类
- 统一异常处理和日志记录

**达到什么目的**：
- 提供获取视频信息的方法，调用 FFprobe 分析视频文件
- 提取关键信息：时长、格式、分辨率、帧率
- 使用内部类 VideoInfo 封装返回的视频信息
- 异常处理：获取失败时抛出业务异常

文件位置：`src/main/java/com/anwen/xiamubackend/utils/FFmpegUtil.java`

```java
@Slf4j
@Component
public class FFmpegUtil {

  /**
   * 获取视频信息
   * @param videoPath 视频文件路径
   * @return 视频信息
   */
  public VideoInfo getVideoInfo(String videoPath) {
    try {
      FFprobe probe = FFprobe.atPath();
      FFprobeResult result = probe.setInput(videoPath).execute();

      List<Stream> streams = result.getStreams();
      if (streams.isEmpty()) {
        throw new BusinessException(ErrorCode.SYSTEM_ERROR, "无法获取视频信息：视频流为空");
      }

      // 查找视频流
      Stream videoStream = streams.stream()
              .filter(s -> s.getCodecType() == StreamType.VIDEO)
              .findFirst()
              .orElse(streams.get(0));

      VideoInfo info = new VideoInfo();

      // 获取时长（秒）
      Float duration = result.getFormat().getDuration();
      if (duration != null) {
        info.setDuration(duration.longValue());
      }

      // 获取格式（编码格式）
      String codec = videoStream.getCodecName();
      if (codec != null) {
        info.setFormat(codec);
      }

      // 获取分辨率
      info.setWidth(videoStream.getWidth());
      info.setHeight(videoStream.getHeight());

      // 获取帧率
      Rational frameRate = videoStream.getRFrameRate();
      if (frameRate != null) {
        double fps = (double) frameRate.getNumerator() / frameRate.getDenominator();
        info.setFrameRate(String.format("%.2f", fps));
      }

      log.info("视频信息获取成功: duration={}s, format={}, {}x{}, fps={}",
              info.getDuration(), info.getFormat(), info.getWidth(), info.getHeight(), info.getFrameRate());

      return info;

    } catch (BusinessException e) {
      throw e;
    } catch (Exception e) {
      log.error("获取视频信息失败: {}", videoPath, e);
      throw new BusinessException(ErrorCode.SYSTEM_ERROR, "获取视频信息失败: " + e.getMessage());
    }
  }

    /**
     * 视频信息内部类
     */
    @Data
    public static class VideoInfo {
        private Long duration;      // 时长（秒）
        private String format;      // 格式
        private Integer width;      // 宽度
        private Integer height;     // 高度
        private String frameRate;   // 帧率
    }
}
```

### 目标

文件位置：`src/main/java/com/anwen/xiamubackend/utils/AudioExtractUtil.java`

```java
@Slf4j
@Component
@RequiredArgsConstructor
public class AudioExtractUtil {

    private final StorageConfig storageConfig;

    /**
     * 从视频提取音频
     * @param videoPath 视频文件路径
     * @return 音频文件路径
     */
    public String extractAudio(String videoPath) {
        // 生成音频文件路径
        String audioPath = generateAudioPath(videoPath);

        // 确保输出目录存在
        Path outputPath = Paths.get(audioPath);
        File outputDir = outputPath.getParent().toFile();
        if (!outputDir.exists()) {
            outputDir.mkdirs();
        }

        try {
            log.info("开始提取音频: {} -> {}", videoPath, audioPath);

            // 使用 FFmpeg 提取音频
            FFmpeg.atPath()
                    .addInput(UrlInput.fromPath(Paths.get(videoPath)))
                    .addOutput(UrlOutput.toPath(outputPath)
                            // 设置音频编解码器为 mp3
                            .setMainStreamType(StreamType.AUDIO)
                            // 设置音频编码器
                            .setAudioCodec("libmp3lame")
                            // 设置采样率：16000 Hz（Whisper 推荐）
                            .setAudioSampleRate(16000)
                            // 设置声道：1（单声道）
                            .setAudioChannels(1)
                            // 设置比特率：64 kbps
                            .setAudioBitRate(64000))
                    .setOverwriteOutput(true)
                    .execute();

            log.info("音频提取成功: {}", audioPath);
            return audioPath;

        } catch (Exception e) {
            log.error("音频提取失败: {}", videoPath, e);
            throw new BusinessException(ErrorCode.SYSTEM_ERROR, "音频提取失败: " + e.getMessage());
        }
    }

    /**
     * 生成音频文件路径
     * @param videoPath 视频文件路径
     * @return 音频文件路径
     */
    private String generateAudioPath(String videoPath) {
        // 获取视频文件的日期路径（如 2026/03/07）
        LocalDate now = LocalDate.now();
        String datePath = Paths.get(
                String.valueOf(now.getYear()),
                String.format("%02d", now.getMonthValue()),
                String.format("%02d", now.getDayOfMonth())
        ).toString();

        // 生成音频文件名（使用视频文件名的时间戳部分）
        Path videoFileName = Paths.get(videoPath).getFileName();
        String videoName = videoFileName.toString();
        String nameWithoutExt = videoName.substring(0, videoName.lastIndexOf('.'));
        String audioName = "audio_" + nameWithoutExt.replace("video_", "") + ".mp3";

        // 构建完整路径
        return Paths.get(storageConfig.getAudioPath(), datePath, audioName).toString();
    }
}
```

**注意**：
- 需要导入 `com.anwen.xiamubackend.exception.BusinessException` 和 `ErrorCode`
- 需要导入 `com.anwen.xiamubackend.config.StorageConfig`
- FFmpeg 参数说明：
  - `-vn`：禁用视频（由 `setMainStreamType(StreamType.AUDIO)` 替代）
  - `-acodec libmp3lame`：使用 MP3 编码器
  - `-ar 16000`：采样率 16000 Hz
  - `-ac 1`：单声道
  - `-ab 64k`：比特率 64 kbps

#### 步骤 4：创建异步音频提取服务

**为什么要这样做**：
- 音频提取是耗时操作，不应阻塞上传接口
- 使用 Spring @Async 实现异步处理
- 解耦业务逻辑，便于维护和测试

**达到什么目的**：
- 创建音频提取服务，提供异步提取方法
- 处理成功后更新 Video 实体的 audioPath 和状态
- 处理失败后更新 errorMessage 和状态为 FAILED
- 记录详细的处理日志

文件位置：`src/main/java/com/anwen/xiamubackend/service/AudioExtractService.java`

```java
@Slf4j
@Service
@RequiredArgsConstructor
public class AudioExtractService {

    private final VideoMapper videoMapper;
    private final AudioExtractUtil audioExtractUtil;

    /**
     * 异步提取音频
     * @param videoId 视频ID
     */
    @Async
    public void extractAudioAsync(Long videoId) {
        log.info("开始异步提取音频: videoId={}", videoId);

        // 1. 查询视频信息
        Video video = videoMapper.selectById(videoId);
        if (video == null) {
            log.error("视频不存在: videoId={}", videoId);
            return;
        }

        // 2. 检查视频路径
        if (video.getUrl() == null || video.getUrl().isEmpty()) {
            log.error("视频路径为空: videoId={}", videoId);
            updateExtractFailed(video, "视频路径为空");
            return;
        }

        // 3. 更新状态为处理中
        updateStatus(video, VideoStatusEnum.PROCESSING.getCode());

        try {
            // 4. 提取音频
            String audioPath = audioExtractUtil.extractAudio(video.getUrl());

            // 5. 更新数据库
            video.setAudioPath(audioPath);
            video.setStatus(VideoStatusEnum.WAITING.getCode());  // 提取成功，等待下一步 ASR
            videoMapper.updateById(video);

            log.info("音频提取成功: videoId={}, audioPath={}", videoId, audioPath);

        } catch (Exception e) {
            log.error("音频提取失败: videoId={}", videoId, e);
            updateExtractFailed(video, "音频提取失败: " + e.getMessage());
        }
    }

    /**
     * 更新状态
     */
    private void updateStatus(Video video, String status) {
        video.setStatus(status);
        videoMapper.updateById(video);
    }

    /**
     * 更新提取失败
     */
    private void updateExtractFailed(Video video, String errorMessage) {
        video.setStatus(VideoStatusEnum.FAILED.getCode());
        video.setErrorMessage(errorMessage);
        videoMapper.updateById(video);
    }
}
```

   - 应该看到 "开始异步提取音频" 日志
   - 应该看到 "音频提取成功" 日志
5. 验证音频文件：
   - 使用播放器打开音频文件，确认可以正常播放
   - 检查音频格式、采样率等参数

### 注意事项

1. **异步执行**：音频提取是异步执行的，上传接口会立即返回，音频提取在后台进行
2. **状态查询**：前端可以通过查询接口轮询视频状态，了解音频提取进度
3. **错误重试**：当前版本不支持自动重试，提取失败需要用户重新上传
4. **文件清理**：音频提取后保留视频文件，用户可能需要回看
5. **大文件处理**：大视频文件的音频提取可能需要较长时间，需要合理设置超时时间
